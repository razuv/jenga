# Jenga

3D Jenga на Three.js и Rapier. Авторитетная серверная физика, комнаты до 6 участников, локальная игра на 1–6 человек. Деревянные текстуры генерируются локально. Игроки сидят вокруг стола с случайно назначенными мемами вместо лиц. Мемы одинаковы для всех участников комнаты и хранятся в public/memes.

## Запуск

Node.js 22.12+:

```
npm install
npm run dev
```

Откройте http://localhost:3000. Через «Пригласить друзей» выберите локальный или онлайн-режим. Создатель онлайн-комнаты копирует ссылку и после подключения игроков нажимает «Начать игру».

Выберите блок ниже двух верхних этажей, потяните его вдоль длинной стороны мышью или пальцем. Полностью извлечённый блок после отпускания автоматически переносится наверх; завершение хода обрабатывает сервер. Незавершённое вытягивание можно продолжить повторным захватом блока или отменить выбором другого; застрявший захват автоматически освобождается через 6 секунд. С клавиатуры: стрелки выбирают блок, Enter берёт его, влево/вправо вытягивают, Enter отпускает, Escape отменяет. Камера вращается перетаскиванием пустого пространства, масштаб — колесом / жестом двумя пальцами.

## Публикация

```
npm run build
NODE_ENV=production PORT=3000 node server.js
```

Нужен постоянный Node.js-сервер с поддержкой WebSocket (не статический хостинг). HTTPS настраивается на хостинге или reverse proxy. Все участники должны открывать один адрес сервера; localhost доступен только с того же компьютера. В домашней сети используйте LAN-адрес компьютера.

`npm test` проверяет устойчивость, ограничения выбора и перенос блоков. Комнаты хранятся в памяти; перезапуск сервера завершает партии. При отключении участник покидает комнату, ход переходит оставшимся. Физика приближённая; вытягивание ограничено продольной осью блока.
